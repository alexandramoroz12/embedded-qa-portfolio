# Homework — Python/Pytest Embedded Automation

Студент отримує `homework_buggy`, `automation`, `requirements`.

## Завдання
1. Підключити Python до Serial/Wokwi.
2. Запустити готовий Pytest suite.
3. Для кожного FAIL визначити: test / environment / communication / requirement / firmware.
4. Додати щонайменше 5 власних parametrized boundary/negative cases.
5. Перевірити timeout.
6. Додати контрольований precondition та cleanup.
7. Зберегти evidence для кожного підтвердженого firmware defect.
8. Оформити короткий Test Summary.

Не читати instructor key до завершення.
