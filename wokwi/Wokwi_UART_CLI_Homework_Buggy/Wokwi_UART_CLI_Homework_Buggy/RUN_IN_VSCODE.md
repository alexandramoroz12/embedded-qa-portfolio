# Запуск симуляції у VS Code

## Одноразове налаштування
1. Встановіть розширення **PlatformIO IDE** і **Wokwi Simulator** (VS Code запропонує їх автоматично з `.vscode/extensions.json`).
2. Активуйте ліцензію Wokwi: `F1` → **Wokwi: Request a New License** (безкоштовно, потрібен акаунт Wokwi).

## Запуск
1. Відкрийте у VS Code **саме цю папку** (`File → Open Folder…`) — у корені мають бути `platformio.ini`, `wokwi.toml`, `diagram.json`.
2. Зберіть прошивку: `F1` → **PlatformIO: Build** (перша збірка завантажує toolchain ESP32, це кілька хвилин). Після кожного оновлення архіву — Build ще раз.
3. Запустіть симулятор: `F1` → **Wokwi: Start Simulator** (або відкрийте `diagram.json` і натисніть ▶).
4. Клацніть у вкладку терміналу Wokwi, наберіть `help` і натисніть Enter. Набраний текст у терміналі Wokwi **не відображається** — це нормально, команда виконається після Enter.

## Альтернатива: PlatformIO Serial Monitor (з відображенням введення)
Поки симулятор запущено, він відкриває порт `rfc2217://localhost:4000`.
`F1` → **PlatformIO: Serial Monitor** підключиться до нього автоматично (`monitor_echo = yes` — видно, що ви набираєте).

## Типові проблеми
- **"firmware not found"** — не виконано Build, або відкрито батьківську папку замість цієї.
- **Немає виводу / не приймає ввід** — перевірте, що симулятор не на паузі; перезапустіть його після нового Build.
- **Serial Monitor не підключається** — спочатку запустіть симулятор, потім монітор.
- **CLI не відповідає на Enter** — ви запускаєте стару прошивку: виконайте **PlatformIO: Build** і перезапустіть симулятор.
